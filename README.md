# 🌱 EcoMarket - Tienda en Línea Sustentable

**EcoMarket** es una aplicación web e-commerce desarrollada únicamente con **HTML5 semántico** y **CSS3 puro** (Mobile First), orientada al consumo responsable.

---

## 🛠️ Tecnologías
- **HTML5 Semántico:** Estructura limpia y accesible.
- **CSS3 Modular:** Estilos organizados sin frameworks externos.
- **Diseño Mobile First:** Maquetado responsivo.
- **Sin JavaScript:** Funcionalidades basadas puramente en CSS.
